# Textes et traductions

- Aucun texte en dur dans les composants : chaque texte visible passe par une clé vue-i18n.
- Toute clé ajoutée ou modifiée dans `src/i18n/fr.js` l'est aussi dans `src/i18n/en.js` (même structure, même clé).
- Le français est la langue par défaut ; l'anglais est une vraie traduction, pas un mot à mot.
- Le titre de Gilbert est « Product Designer / Builder » (FR et EN).
- Phrases courtes, verbes d'action, vouvoiement du visiteur.
- Règles de contenu de `CLAUDE.md` : rien d'inventé, pas de durée, WordPress seulement pour Mélodie, aucune mention de recherche de CDI.
